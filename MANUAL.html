Guía de Instalación

git clone [url-del-repositorio] cd portfolio

# Instalar dependencias de PHP composer install # Instalar dependencias de Node npm install

# Copiar archivo de entorno cp .env.example .env # Generar clave de aplicación php artisan key:generate # Crear enlace simbólico de storage php artisan storage:link

Editar el archivo .env con las credenciales de la base de datos:

DB_CONNECTION=mysql DB_HOST=127.0.0.1 DB_PORT=3306 DB_DATABASE=floresyalgomas DB_USERNAME=root DB_PASSWORD=

Luego ejecutar las migraciones:

php artisan migrate php artisan db:seed

# Iniciar servidor de desarrollo php artisan serve # En otra terminal, compilar assets (opcional, solo para auth) npm run dev

El sistema estará disponible en http://localhost:8000

Gestión de Productos

El sistema de productos permite gestionar el catálogo completo de la floristería, incluyendo arreglos, ramos y complementos.

Crear un Producto

Acceda a Productos → Nuevo Producto y complete los siguientes campos:

Campo Descripción Requerido
Referencia Código único del producto (SKU) Sí
Nombre Nombre del producto Sí
Descripción Descripción detallada del producto No
Categoría Categoría a la que pertenece Sí
Tiene variantes Si el producto tiene tallas/colores No
Controlar stock Si se debe verificar disponibilidad No

Imágenes del Producto

  • Cada producto puede tener múltiples imágenes
  • Una imagen debe ser marcada como principal
  • Las imágenes pueden ser reordenadas
  • Formatos soportados: JPG, PNG, WebP

Variantes de Producto

Si el producto tiene variantes (tallas, colores), se pueden configurar:

  • Talla: Pequeño, Mediano, Grande, etc.
  • Color: Variaciones de color disponibles
  • SKU: Código único por variante
  • Precio: Precio específico de la variante
  • Stock: Stock independiente por variante

El sistema soporta múltiples listas de precios para diferentes tipos de clientes:

Lista General

Precio base para todos los clientes

Lista Mayorista

Categorías

Las categorías organizan los productos y se dividen en dos tipos:

Categorías por Ocasión

Organizan productos según el evento o momento:

  • Cumpleaños

Gestión de Inventario

Control de Stock

El modelo StockProducto gestiona el inventario:

  • cantidad_disponible: Stock actual disponible
  • cantidad_reservada: Stock reservado en carritos
  • stock_minimo: Umbral para alertas
  • alerta_stock_bajo: Activar notificaciones

Movimientos de Stock

El sistema registra todos los movimientos de inventario:

Tipo Descripción Efecto
Entrada Compra de inventario + Stock
Salida Venta completada - Stock
Reserva Producto en carrito Stock reservado
Ajuste Corrección manual +/- Stock

Alertas de Stock Bajo

El sistema genera alertas cuando:

  • El stock cae por debajo del mínimo configurado
  • Un producto agota su inventario
  • Se detecta una alta demanda

Sistema de Descuentos

El sistema de descuentos permite crear promociones flexibles y códigos promocionales.

Tipos de Descuento

Porcentaje

Descuento por porcentaje del total. Ej: 10% de descuento

Cantidad Fija

Descuento de monto fijo. Ej: $5.000 de descuento

Aplicabilidad

Aplica a Descripción
Orden completa Se aplica al total de la compra
Productos específicos Solo aplica a productos seleccionados
Categorías Aplica a todos los productos de una categoría

Validaciones

Los descuentos pueden tener las siguientes restricciones:

  • Monto mínimo de compra: Compra mínima para aplicar
  • Cantidad mínima de productos: Número de items requeridos
  • Solo primera compra: Exclusivo para nuevos clientes
  • Límite de usos total: Cantidad máxima de usos
  • Límite por cliente: Máximo de usos por email
  • Rango de fechas: Período de vigencia
  • Es acumulable: Puede combinarse con otros descuentos

Crear un Código de Descuento

Acceda a Descuentos → Nuevo Descuento:

  1. Ingrese un código único (ej: VERANO2024)
  2. Seleccione el tipo (porcentaje o cantidad fija)
  3. Configure el valor del descuento
  4. Defina a qué aplica (orden, productos, categorías)
  5. Configure las restricciones necesarias
  6. Establezca el período de vigencia
  7. Active el descuento

Arma tu Ramo

La funcionalidad "Arma tu Ramo" permite a los clientes crear ramos personalizados mediante un wizard de 4 pasos.

1 Seleccionar Estilo
2 Elegir Flores
3 Seleccionar Envoltura
4 Resumen y Extras

Paso 1: Seleccionar Estilo

El cliente elige el estilo base del ramo:

  • Cada estilo tiene un precio base
  • Define el rango de flores permitido (mínimo/máximo)
  • Incluye imagen de referencia y descripción
Los estilos se gestionan en Configuración → Estilos de Ramo

Paso 2: Elegir Flores

El cliente selecciona las flores para su ramo:

  • Catálogo de flores disponibles con imagen y precio
  • Filtro por color
  • Selector de cantidad por flor
  • Validación del rango mínimo/máximo del estilo
  • Cálculo dinámico del subtotal de flores

Paso 3: Seleccionar Envoltura

El cliente elige el tipo de empaque:

  • Cada envoltura tiene un precio adicional
  • Opciones como papel kraft, celofán, tela, etc.
  • Vista previa de la envoltura

Paso 4: Resumen y Extras

En el paso final:

  • Ver resumen completo del ramo
  • Agregar productos adicionales (chocolates, peluches, etc.)
  • Escribir mensaje para la tarjeta
  • Ver desglose de precios
  • Agregar al carrito

Cálculo del Precio

Total = Precio Base del Estilo + (Cantidad × Precio por cada Flor) + Precio de la Envoltura + Subtotal de Adicionales

Proceso de Pago

Al confirmar la compra:

  1. Se crea la compra en estado "pendiente"
  2. Se genera una referencia única
  3. Se redirige a Transbank WebPay
  4. El cliente completa el pago
  5. Transbank retorna el resultado
  6. Se actualiza el estado de la compra
  7. Se envía confirmación por email

Sistema de Templates

El sistema utiliza el patrón Strategy para permitir múltiples diseños de tienda intercambiables.

Arquitectura

TemplateTienda (Modelo BD) ↓ TemplateResolver (Context - Strategy Pattern) ↓ {Default, Brasilia}TemplateStrategy (Strategies) ↓ TemplateStrategyInterface (Contrato)

Templates Disponibles

Template Default

Diseño clásico y elegante con Bootstrap 5. Ideal para la mayoría de floristerías.

Vistas: tienda.index, tienda.categoria, tienda.producto
Template Brasilia

Diseño moderno con carruseles Swiper y animaciones. Inspirado en tiendas de moda.

Vistas: tienda.brasilia_*

Agregar Nuevo Template

  1. Crear las vistas Blade en resources/views/tienda/
  2. Crear clase Strategy en app/Services/Templates/Strategies/
  3. Registrar en TemplateResolver::$strategyMap
  4. Insertar registro en tabla templates_tienda
  5. Limpiar cache
Para instrucciones detalladas, consulte la sección "Sistema de Templates de Tienda" en el archivo CLAUDE.md.
